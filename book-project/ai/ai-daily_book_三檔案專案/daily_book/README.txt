daily.book 日常選書店

檔案：
- index.html：網頁結構
- css/style.css：網站外觀與響應式
- js/script.js：書籍資料、搜尋、表單互動
- images/：放置書籍封面與主視覺圖片

圖片：
請將八本書封面放入 images 資料夾，檔名依序為 book-01.jpg 至 book-08.jpg。
主視覺背景圖可命名為 reading-banner.jpg。
如果尚未放入圖片，書籍區會自動顯示文字封面，不會出現破圖圖示。

執行：
直接用瀏覽器開啟 index.html，或使用 VS Code Live Server。
Bootstrap 與 Bootstrap Icons 使用 CDN，預覽時需要網路。

注意：
加入讀書會與登入目前是前端練習示範，尚未連接資料庫。
