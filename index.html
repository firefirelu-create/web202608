關於我

我是一位重視實作、溝通與持續精進的學習者，對生活科技、數位工具與網頁應用抱持高度興趣。面對新工具時，我習慣先理解需求，再拆解問題、逐步測試，並整理成清楚易懂的操作流程。

希望投入生活科技應用領域，協助不同背景的使用者善用數位工具，提升工作效率與生活品質；也願意持續學習新技術，將想法轉化為可操作的成果。

03 · Learning Journey

學習歷程

把學習變成可以看見的成果，透過練習、製作與修正，逐步建立科技應用能力。

階段一｜基礎建立

網頁結構與版面設計

學習 HTML、CSS 與 Bootstrap，練習製作個人履歷、資訊展示頁面及響應式表格。

  • 理解 HTML 語意標籤與網頁基本結構。
  • 運用 CSS 調整色彩、間距、排版與手機版面。
  • 使用 Bootstrap 元件建立一致且易閱讀的介面。
階段二｜實作應用

程式邏輯與資料應用

透過實際練習理解程式邏輯，並探索資料整理與日常工作流程的數位化。

  • 練習 JavaScript 基礎、事件處理與表單驗證。
  • 認識 Google 試算表與 Apps Script 的資料應用方式。
  • 練習除錯、閱讀錯誤訊息並逐步驗證修正結果。
我的學習方法：先理解需求，再拆解步驟；先完成基本功能，再持續優化使用體驗。每一次除錯，都是更了解科技如何運作的機會。
