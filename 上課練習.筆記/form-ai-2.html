巴洛克古典人物與華服設計

深入解析古典服飾褶皺、蕾絲雕花、珠寶光澤與人物骨架動態，打造極具辨識度的華麗主角群。

COURSE Ⅱ · 分鏡敘事

戲劇張力分鏡與腳本編劇

掌握視線引導、跨頁大場面構圖與節奏留白技巧，讓每一格畫面都充滿扣人心弦的舞台感。

  • 起承轉合劇本大綱建構
  • 情緒特寫與運鏡視角切換
  • 商業條漫與頁漫雙規格實戰

COURSE Ⅲ · 場景光影

宮廷建築透視與光影氛圍

從一點至三點透視出發，結合 3D 輔助模型與浪漫主義光影配色，建立宏偉的世界觀舞台。

  • 古典廊柱與水晶吊燈透視
  • 晨曦、燭光與夜宴色調演練
  • 快速背景完稿流程優化

個人漫畫作品集與數位系統實作

結合原創連載企劃與個人作品展示網頁概念（支援 php / java / Pyton / MySQL 等技術選修），打造完整創作者品牌。

  • 編輯部投稿規格與企劃書
