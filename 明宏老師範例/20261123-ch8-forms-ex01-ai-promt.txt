# 巨匠電腦風格｜課程諮詢表單 UI/UX 改造

請依據我提供的 HTML、CSS、JavaScript 程式碼，將目前的「補習班課程資料收集表單」改造成具有「巨匠電腦」風格的專業資訊教育機構課程諮詢網站。

### 一、視覺設計
1. 參考巨匠電腦的品牌形象，以紅色、白色、深灰色為主要配色，呈現專業、現代且具有科技感的視覺風格。
2. 加入完整的 Navbar、品牌形象 Banner、課程介紹、報名表單及 Footer，讓網頁具有正式商業網站的完整度。
3. 使用 Bootstrap 進行 RWD 響應式排版，搭配自訂 CSS 美化卡片、按鈕、輸入欄位、背景與陰影。
4. 加入適當的 Font Awesome 圖示、科技教育相關圖片及具有吸引力的招生文案。
5. 整體設計需具備良好的視覺層次、留白、操作體驗與商業質感，避免呈現傳統練習作業的陽春版面。

### 二、表單設計
1. 保留所有既有表單欄位，包括 Input、Datalist、Select、Checkbox、Radio、Switch、Range。
2. 將表單重新規劃為清楚的分區，例如「基本資料」、「課程需求」、「學習偏好」。
3. 優化表單排列方式，電腦版採雙欄或適當的網格排版，手機版自動調整為單欄。
4. 保留原本的欄位驗證提示，並美化確認、取消按鈕及資料確認結果區塊。

### 三、程式功能限制
1. **保留原本所有 JavaScript、jQuery 的功能與操作邏輯，不得任意刪除或簡化。**
2. 保留所有原本的 `id`、`class`、`flag` 變數及事件監聽，確保既有程式能正常執行。
3. 保留原本 AJAX 載入 `CityCountyData.json` 的功能及檔案路徑。
4. 不使用 Vue、React 或其他前端框架，僅使用 HTML5、CSS3、Bootstrap、jQuery。
5. 不加入不必要的複雜 JavaScript 功能，改造重點放在 UI/UX。

### 四、輸出要求
1. 提供完整、可直接執行的 `index.html` 程式碼。
2. CSS 可以直接寫在 `<style>` 區塊中。
3. 保留原本的外部 CSS、JavaScript 檔案引用路徑。
4. 不得省略任何原始表單功能與程式碼。
5. 確保所有表單驗證、資料收集、取消重設、Switch、Range 及確認結果功能皆能正常運作。
